# Archivo — proyecto de automatización para clínicas dentales

Estos catorce documentos son el trabajo del proyecto **anterior** de FARO: automatización operativa por suscripción para clínicas dentales (WhatsApp fuera de horario, confirmación de citas, seguimiento de pacientes).

**No describen el negocio actual.** Desde agosto de 2026, FARO es el estudio de diseño web y gráfico de El Bierzo y León, cuyo plan está en `plan-negocio/` y cuya web está en la raíz de este repositorio.

Se archivan, no se borran, porque contienen investigación y método reutilizables:

| Documento | Qué se puede reutilizar |
|---|---|
| `FARO_ESTRATEGIA_MARCA.md` | La narrativa del faro y el elevator pitch, que sobreviven al cambio de sector |
| `FARO_MODELO_NEGOCIO.md` | Business Model Canvas, Lean Canvas y el método para definir ICP y buyer persona |
| `FARO_UX_ARQUITECTURA.md` | Mapa de sitio y user flows, aplicables a cualquier web de servicios |
| `FARO_WEB_COPY.md` | Método de redacción y SEO on-page |
| `FARO_SEO_CONTENIDOS.md` | Método de keyword research y calendario editorial |
| `FARO_PROCESO_COMERCIAL.md` | Embudo de outbound a referidos, adaptable a la prospección de El Bierzo |
| `FARO_VENTA_ADAPTATIVA.md` | Adaptar la venta al perfil de riesgo del comprador (evidencia 🟠, sin validar) |
| `FARO_NEGOCIO_SOSTENIBLE.md` | Distinguir un ingreso puntual de un proceso de adquisición repetible |
| `FARO_MARCA_Y_MARGEN.md` | La marca como palanca de margen (evidencia 🟡, hipótesis) |
| `FARO_SISTEMA_MULTIAGENTE.md` | El sistema de agentes de validación, independiente del sector |
| `FARO_TESIS_MVP_60DIAS.md` | Estructura de una tesis de negocio y de un plan de 60 días |
| `FARO_BIBLIOTECA_AUTOMATIZACIONES.md`, `FARO_AGENTES_VERTICALES.md` | Específicos del producto de clínicas; valor sobre todo de archivo |

`FARO_IDENTIDAD_VISUAL.md` **no está aquí**: sigue en la raíz porque es el sistema visual que usa la web actual.

Si algún día se retoma el proyecto de clínicas, hay que decidir antes si comparte marca con el estudio o si necesita una propia.
