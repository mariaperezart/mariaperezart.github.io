## 🎯 BEST PRACTICES

✅ **Hooks:** First 0.5-1 second is CRITICAL  
✅ **Transitions:** Change angles every 3-5 seconds  
✅ **Captions:** 75%+ watch rate (people watch muted)  
✅ **CTA:** Clear call-to-action (comment, share, tag, DM)  
✅ **Timing:** Post 6-9 AM, 12-1 PM, 7-11 PM  
✅ **Testing:** A/B test 1-2 variations first, then scale wins
