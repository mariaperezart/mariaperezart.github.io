## ⬇️ PASO 0: DESCARGAR CAPCUIT

## 📹 PASO 1: IMPORTAR VIDEO (2 MIN)

### Crear Nuevo Proyecto
```
1. Tap "Create a Video"
2. Select "New Project"
3. Choose your 28MB DJI video from Photos
4. Wait for import (may take 30-60 seconds for large files)
```

### En la pantalla de edición, verás:
```
TOP: Preview (tu video en grande)
MIDDLE: Timeline (para editar)
BOTTOM: Tools (audio, texto, etc.)
```

---

## 🎵 PASO 2: AGREGAR AUDIO (2 MIN)

**OPCIÓN A: Trending Sound (Recommended)**
```
1. Tap "Audio" (bottom toolbar)
2. Tap "Sounds" 
3. Search for THIS WEEK'S trending sound
   - Go to TikTok/Reels
   - See what's viral THIS WEEK
   - Search that exact sound
4. Tap to add to your video
5. Sound auto-syncs to beat
```

**OPCIÓN B: Music from Library**
```
1. Tap "Audio" → "Music"
2. Search "cinematic" or "aerial" or "ambient"
3. Pick one that matches your vibe
4. Drag to timeline
```

**⚠️ IMPORTANT:**
- Audio should start at 0:00 of your video
- Volume should be 100% (default)
- If video is longer than song, song will loop (okay)

---

## ✂️ PASO 3: TRIM VIDEO (2 MIN)

**If your video is too long:**

```
1. Tap the video on timeline (highlight it)
2. Adjust the LEFT edge (where video starts)
3. Adjust the RIGHT edge (where video ends)
4. Typical sweet spot: 20-30 seconds for TikTok

EXAMPLE:
- Start at 0:05 (skip boring intro)
- End at 0:30 (perfect TikTok length)
```

**Pro Tip:** Keep the BEST 30 seconds. First 2 seconds must be STUNNING.

---

## 📝 PASO 4: ADD TEXT OVERLAYS (4 MIN)

### First Text (The Hook - 0-1 second)

```
1. Tap "Text" (bottom toolbar)
2. Type your hook text
   Example: "POV: You can fly"
3. Tap the text to customize:
   - Font: Pick "Bebas" or "Montserrat" (bold)
   - Size: LARGE (60-80pt)
   - Color: WHITE with black outline
   - Position: Top or Center
4. Drag text START point to 0:00
5. Drag text END point to 1:00 (shows for 1 sec)
6. Adjust position on screen (keep text away from edges)
```

### Second Text (Main Message - 2-5 seconds)

```
1. Tap "+" to add ANOTHER text
2. Type your message
   Example: "This changes everything"
3. Repeat styling (bold, large, white+outline)
4. Position: Different place than first text
   (Example: bottom center if first was top)
5. Set timing: Start 2:00, End 5:00
```

### Third Text (Call-to-Action - 15-20 seconds)

```
1. Add another text
2. Type your CTA
   Example: "Tag someone 👇"
   or "Like if you'd try this"
   or "Comment where you'd go"
3. Make it LARGE and BOLD
4. Set timing: Start at 15:00, End at final second
5. Position: ALWAYS bottom (easy to tap)
```

### Optional Fourth Text (Hashtag - Last 3 seconds)

```
1. Last text overlay
2. Type: "#FYP #Viral #DroneLife" (or your hashtags)
3. Smaller size (30-40pt)
4. Position: Bottom corner
5. Timing: Last 3 seconds only
```

**STYLING TIPS:**
- Font: Bold sans-serif (Bebas, Montserrat, Arial)
- Color: WHITE text, BLACK outline (readable everywhere)
- Size: Test on phone - must be readable from arm's length
- Keep moving (don't overlap on same spot)

---

## 🎬 PASO 5: ADD TRANSITIONS (1 MIN)

**Optional but recommended for 20%+ more engagement**

### Between Video Cuts (if applicable)

```
1. Tap "Transition" (middle section of timeline)
2. Choose: "Fade" or "Zoom" (avoid fancy ones)
3. Duration: 0.3-0.5 seconds
4. Position: Between major video cuts
```

**Which transitions work best:**
- ✅ Fade (professional, always works)
- ✅ Zoom (creates drama, use sparingly)
- ✅ Cut (instant, matches music beats)
- ❌ Spin, Whip, Flip (too distracting)

**Rule:** Max 1 transition every 4-5 seconds

---

## 🎨 PASO 6: COLOR GRADING (2 MIN)

**Make video POP visually**

```
1. Tap "Effects" → "Adjust"
2. Find these sliders:
   
   SATURATION: Increase to +10
   (Makes colors more vivid, not overwhelming)
   
   BRIGHTNESS: Increase to +2
   (Slightly lighter, watch for blown-out highlights)
   
   CONTRAST: Increase to +8
   (Makes details stand out)
   
   TEMPERATURE: Increase to +2
   (Adds warm golden tone, good for aerials)

3. Tap "Apply"
```

**Before/After Check:**
- Tap "Compare" to see before/after
- Should look punchy but natural
- If too saturated, reduce saturation to +5

---

## 📤 PASO 7: EXPORT FOR SOCIAL MEDIA (2 MIN)

### Export Settings

```
1. Tap "Export" (top right)
2. RESOLUTION SETTINGS:
   - Select "1080x1920" (this is CRITICAL)
   - Format: 9:16 (vertical)
   
3. QUALITY: "High" (default is fine)

4. SIZE: Should be 20-100MB (normal for social)

5. Tap "Export"
```

### After Export

```
1. Video saves to your PHOTOS
2. Should take 1-3 minutes for 1080x1920
3. When done, you'll get notification
4. Video is ready to post!
```

## 🚨 COMMON MISTAKES TO AVOID

❌ **Text too small**
- Can't read on phone from normal distance

❌ **Audio too quiet**
- Bring to 100% volume, test on speaker

❌ **Too many transitions**
- More than 1 every 4 seconds = distracting

❌ **Exporting wrong size**
- MUST be 1080x1920 (vertical 9:16)
- Not 1920x1080 (that's horizontal)

❌ **Posting during low-traffic times**
- Post 6-9 AM, 12-1 PM, or 7-11 PM only

❌ **Hashtags with quotes or special characters**
- Instagram/TikTok won't recognize them

❌ **Captions without personality**
- "Nice video" gets 10% of engagement
- "Tag someone who needs this energy" gets 100%+
