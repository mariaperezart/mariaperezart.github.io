## 🎯 LA CIENCIA DE LOS VIDEOS VIRALES

### LA REGLA DE LOS 3 SEGUNDOS
- **0-0.5s:** HOOK visual (lo mejor del video)
- **0.5-3s:** Texto overlay + audio hook
- **3-15s:** Contenido principal + CTA

### POR QUÉ LOS VIDEOS SE HACEN VIRALES
1. **Strong Hook** (primera imagen impactante)
2. **Emotional Trigger** (asombro, curiosidad, FOMO, aspiración)
3. **Relatable** (los viewers se ven reflejados)
4. **Binge-worthy** (watch time >80%)
5. **Shareable** (el caption/mensaje resuena)

## 📱 OPTIMIZACIÓN ESPECÍFICA POR PLATAFORMA

### PARA INSTAGRAM REELS
- **Duración:** 15-30 segundos (punto dulce)
- **Audio:** Sonidos trending (Librería de sonidos de Instagram)
- **Texto:** Max 3-4 overlays (no saturado)
- **Hook:** Visual primero 0.5s (sin texto inicialmente)
- **CTA:** "Desliza para más" / "Sígueme para el próximo"
- **Colores:** Boost saturation ligero (+5-10%)

### PARA TIKTOK
- **Duración:** 15-25 segundos (el algoritmo favorece duración corta)
- **Audio:** Sonido TRENDING (esta semana, no el mes pasado)
- **Texto:** Bold, grande, alineado a beats musicales
- **Hook:** Texto + audio hook juntos (0-1s)
- **CTA:** "Like si lo intentarías", "Etiqueta a alguien", "Comenta 👇"
- **Colores:** Alto contraste, saturación punchy (+15-20%)
- **Velocidad:** Mezcla normal (1x) con 0.75x/1.25x para drama

### PARA YOUTUBE SHORTS
- **Duración:** 30-45 segundos (puede ser más largo)
- **Audio:** Música original (no requiere trending)
- **Texto:** Tipografía profesional, limpia
- **Hook:** "Espera..." / "Esto te sorprenderá"
- **CTA:** "Suscribite para contenido diario"
- **Estilo:** Cinemático sobre viral

## 🎨 PRINCIPIOS DE EDICIÓN PARA VIRALIDAD

### TRANSICIONES
- **Fade:** Usa para momentos emocionales
- **Zoom:** Usa para impacto/revelación
- **Cut:** Usa para beat-matching (TikTok)
- **Spin:** Evita (demasiado cliché)
- **Whip:** Usa con moderación (puede fallar)

**REGLA:** Max 1 transición cada 3-4 segundos. Más = distracción.

### OVERLAY DE TEXTO
- **Fuente:** Bold sans-serif (Arial, Montserrat, Bebas)
- **Tamaño:** Suficientemente grande para leer en teléfono
- **Color:** Blanco con outline negro (legible en cualquier fondo)
- **Posición:** Sigue la acción (el texto se mueve con el sujeto)
- **Duración:** 2-3 segundos por texto

### COLOR GRADING
Para contenido "Belleza Aérea":
```
Saturación: +5 a +15% (dron ya está saturado)
Brillo: +2% (no quemes las luces altas)
Contraste: +8% (haz que los detalles destaquen)
Temperatura: +2% cálido (sensación de hora dorada)
Sombras: Levanta +3% (mantén detalles visibles)
```

### ESTRATEGIA DE AUDIO
- **TikTok:** SIEMPRE usa sonido trending (2M+ usos)
- **Reels:** Trending u original (Instagram favorece variedad)
- **YouTube Shorts:** Música original preferida
- **Volumen:** Música 100%, voiceover (si hay) 70%
- **Timing:** El pico musical en el clímax del video
