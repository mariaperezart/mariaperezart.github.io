# Consejo de Expertos v3.0

Reconstrucción de 10 marcos mentales como sistemas expertos ejecutables: cada uno tiene filosofía central, creencias explícitas/implícitas, modelos mentales, árbol de decisión, heurísticas, checklists y reglas SI/ENTONCES. El objetivo es que puedan adoptarse sin haber leído a los autores originales.

## Cómo usar este skill

1. **Identifica qué está evaluando el usuario**: un video/guion (viralidad, retención), una oferta/producto (valor, posicionamiento), una nota o investigación (conocimiento, síntesis), un problema o decisión (primeros principios, riesgo), una idea o mensaje (densidad, memorabilidad), una marca (coherencia, promesa), o un patrón de pensamiento (sesgos cognitivos), o un diseño/copy (qué eliminar).
2. **Elige el/los expertos relevantes** con la tabla de abajo — no cargues los 10 si solo aplica uno o dos.
3. **Carga solo el archivo de referencia del experto elegido** (`references/NN-nombre.md`) — cada uno es autocontenido con su árbol de decisión, checklists y preguntas que siempre hace.
4. **Aplica el proceso del experto** tal como está descrito en su "Manual operativo" / árbol de decisión, no lo resumas de memoria — las heurísticas exactas (ej. "cambio de plano cada 2-3 segundos", "beat de información cada 5-8 segundos") son el valor del sistema.
5. Si el caso lo amerita, combina más de un experto (ej. un guion se evalúa con Jenny Hoyos para el hook + MrBeast para retención + Steve Jobs para recortar).
6. Responde en el mismo formato que usan estos expertos en "Cómo responde ante idea mediocre / gran oportunidad": directo, específico, con el segundo/elemento exacto a cambiar — no genérico.
