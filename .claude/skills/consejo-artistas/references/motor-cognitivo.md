# Motor Cognitivo — Consejo para Artistas

## Austin Kleon — Robar y Mostrar

- SI se espera a "sentirse listo" o tener identidad clara antes de crear ENTONCES se recomienda empezar de todos modos PORQUE la claridad se descubre haciendo el trabajo, no pensándolo antes.
- SI se esconden las influencias reales por miedo a no parecer original ENTONCES se recomienda declararlas abiertamente PORQUE nada surge de la nada, y fingirlo paraliza en vez de liberar.
- SI solo se comparte resultado final pulido ENTONCES se recomienda mostrar también el proceso PORQUE la generosidad de mostrar el proceso genera más conexión que la genialidad aislada del resultado.

## Chris Do — Precio y Valor

- SI el precio se calcula por horas en vez de por valor de negocio del cliente ENTONCES se marca como error de raíz PORQUE cobrar por hora penaliza la eficiencia y limita el ingreso al tiempo disponible.
- SI el cliente dice el primer número en la negociación ENTONCES se marca como ancla perdida PORQUE quien da el número primero controla el marco de toda la conversación posterior.
- SI se baja el precio por culpa de "cobrar mucho por algo que amo" ENTONCES se cuestiona esa razón PORQUE la culpa no es un argumento de negocio válido si el valor generado es real.

## Rick Rubin — Proceso y Fases

- SI se fuerza un resultado predeterminado desde el principio ENTONCES se recomienda soltar el control PORQUE tratar la pieza como experimento abierto produce mejor trabajo que forzar el resultado.
- SI se exige perfección técnica a una idea todavía en fase de semilla ENTONCES se marca como error de fase PORQUE cada fase del proceso creativo exige una actitud distinta, y la exigencia prematura mata la idea.
- SI se guarda todo el trabajo sin compartirlo nunca ENTONCES se recomienda compartir PORQUE compartir repone el flujo de ideas nuevas, guardarlo lo bloquea.

## Jerry Saltz — Disciplina de Trabajo

- SI se espera a la inspiración para producir ENTONCES se recomienda trabajar de todos modos con disciplina constante PORQUE son quienes trabajan todo el tiempo los que eventualmente "se dan cuenta de las cosas".
- SI una pieza no se termina nunca por perseguir la perfección ENTONCES se recomienda terminarla imperfecta PORQUE terminar genera más aprendizaje real que perfeccionar indefinidamente sin cerrar.
- SI un rechazo o crítica negativa detiene la producción futura ENTONCES se marca como error a corregir PORQUE el rechazo es parte del proceso, no un veredicto final sobre el valor del artista.
