# Evidencia de capacidad — Diagnóstico y rediseño de sistemas

**Tesis:** María Gabriela tiene una capacidad repetible para detectar patrones sistémicos ocultos, diseñar soluciones específicas para ese contexto, implementarlas, y generar resultados medibles.

**Por qué esto importa:** Un inversor, un cliente potencial, o tú misma dentro de un año podréis responder "¿María Gabriela tiene una capacidad demostrada?" independientemente de si el producto se llama FARO, si trabaja con clínicas o despachos, si usa WhatsApp o email.

**Cómo se valida:** Cada caso documentado aquí debe responder a cinco preguntas:

1. ¿Viste un patrón que el cliente no estaba viendo? → **Evidencia de diagnóstico**
2. ¿Diseñaste una solución específica para ESTE negocio, no genérica? → **Evidencia de diseño**
3. ¿Se ejecutó realmente la intervención? → **Evidencia de implementación**
4. ¿Qué cambió cuantitativamente? → **Evidencia de impacto**
5. ¿Qué salió diferente a lo que esperabas? → **Evidencia de aprendizaje honesto**

## Qué cuenta como "caso válido"

✅ **Válido:**
- Contacto real con cliente (reunión, llamada, conversación documentada)
- Tu diagnóstico fue documentado ANTES de saber el resultado
- Se implementó al menos una intervención (aunque fuera parcial)
- Hay un resultado observable después de 3+ semanas

❌ **No válido:**
- Consejo que nunca se ejecutó ("si hicieras X...") 
- Recomendación que coincidió con un cambio que habrían hecho igual
- Casos donde solo viste síntomas, no patrones sistémicos
- Historias retrospectivas sin documentación en tiempo real

---

## Validación por agencia

Cada caso documentado aquí debe poder responderse:

1. **Diagnóstico:** ¿Cuál era el patrón que TÚ viste y que el cliente descubrió solo después de tu intervención? (No: "también veía el problema")

2. **Intervención:** ¿Qué cambio concreto causaste? Si fue "les recomendé", ¿por qué tu recomendación fue mejor que lo que otros les recomendaban?

3. **Impacto:** ¿Cuál es la métrica o cambio observable? (No vale "mejoró el ánimo"—vale "pasamos de 5 decisiones/semana a 8 decisiones/semana")

4. **Aprendizaje honesto:** Si TODO salió como esperabas, probablemente hay sesgo de confirmación. ¿Qué suposición resultó equivocada?

## Objetivo a 12 meses

Tener 8-10 casos documentados donde demuestras repetidamente que:
- Diagnosticaste un patrón sistémico que otros pasaban por alto
- Diseñaste una intervención específica (no genérica)
- Generaste un cambio medible
- Documentaste qué salió diferente a tus predicciones

Eso es una base estratégica que te permite pivotar de producto/sector/canal sin perder credibilidad: "He demostrado esto 10 veces con clientes diferentes."
