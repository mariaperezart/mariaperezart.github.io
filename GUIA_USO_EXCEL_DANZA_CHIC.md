# GUÍA DE USO: EXCEL DANZA CHIC V3.1
**Documento de Gestión Mensual — 3 Niveles | ~20 minutos/mes**

---

## 📋 ESTRUCTURA DEL EXCEL: 3 NIVELES

```
NIVEL 1: Manual Estratégico (17 hojas)
├─ Datos internos (llenar 1 sola vez)
├─ Decisiones (revisar trimestralmente)
└─ Referencia (consultar cuando sea necesario)

NIVEL 2: Cuadro de Mando (1 hoja, ~10 minutos/mes)
└─ 10 KPIs con estado Verde/Amarillo/Rojo

NIVEL 3: Base de Datos (células amarillas)
└─ Llenar solo lo amarillo, las fórmulas calculan el resto
```

---

## 🎯 RUTINA MENSUAL: 3 PASOS (20 MINUTOS)

### PASO 1: Primer lunes de cada mes (5 minutos)
**Dónde:** Hoja **"Estado Resultados"**

Registra los números REALES de este mes:

| Concepto | Dónde escribir | Ejemplo |
|----------|---|---|
| Alumnas presentes en mes | Amarillo (Mes 1, Mes 2...) | 45 |
| Ingresos totales | Amarillo | 675 USD |
| Gastos variables (uniforme, material) | Amarillo | 50 USD |
| Alquiler | Amarillo | 250 USD |
| Profesor (si contratado) | Amarillo | 0 USD |
| Marketing | Amarillo | 30 USD |
| Otros gastos fijos | Amarillo | 100 USD |

**⚠️ Importante:** Sin estos números, el cuadro de mando no funciona.

---

### PASO 2: Cuadro de Mando (5 minutos)
**Dónde:** Hoja **"Cuadro Mando"**

**Instrucción:** Completa solo la columna "Mes actual".

**Qué significa cada indicador:**

| Indicador | Verde | Amarillo | Rojo | Qué hacer |
|-----------|-------|----------|------|-----------|
| **Ocupación (%)** | >80% | 60-80% | <60% | Si rojo: revisar precio o marketing |
| **Retención mes 2 (%)** | >85% | 70-85% | <70% | Si rojo: revisar experiencia alumna |
| **Referidos (%)** | >40% | 20-40% | <20% | Si rojo: mejorar satisfacción (NPS) |
| **Margen bruto (%)** | >25% | 10-25% | <10% | Si rojo: costes muy altos o precio bajo |
| **Dependencia fundadora (%)** | <50% | 50-75% | >75% | Si rojo: contratar profesor |
| **NPS** | >50 | 30-50 | <30 | Si rojo: encuesta urgente a madres |
| **Abandono mensual (%)** | <10% | 10-15% | >15% | Si rojo: problema serio |
| **CAC (Cost Acquisition)** | <10 USD | 10-15 | >15 | Si rojo: marketing ineficiente |
| **LTV/CAC ratio** | >3 | 2-3 | <2 | Si rojo: cliente no rentable |
| **Punto equilibrio vs. alumnas** | Alumnas > PE+20% | PE±20% | Alumnas < PE | Si rojo: en pérdida |

**Cómo llenarlos:**

**Ocupación (%):**
```
=  (Alumnas actuales / Capacidad máxima) × 100
   Ej: 45 alumnas / 100 capacidad = 45%
```

**Retención mes 2 (%):**
```
= (Alumnas que renovaron mes 2 / Alumnas mes 1) × 100
  Ej: 40 / 50 = 80%
```

**Referidos (%):**
```
= (Nuevas alumnas por recomendación / Total nuevas) × 100
  Ej: 8 / 20 = 40%
```

**Margen bruto (%):**
```
= (Ingreso - Costes variables) / Ingreso × 100
```

Los demás se calculan automáticamente si completas el "Estado Resultados".

### PASO 3: Análisis de Abandono (5 minutos — SI NECESARIO)
**Dónde:** Hoja **"Análisis Abandono"**

**Solo si el indicador de abandono está en ROJO:**

Llama a 2-3 mamás que sacaron a sus hijas este mes y pregunta:
- ¿Por qué dejó la academia?

Registra en la tabla de "Motivos de abandono":

| Motivo | % |
|--------|---|
| Precio | 30% |
| Horarios incompatibles | 40% |
| Falta de interés | 20% |
| Otro | 10% |

**Acción inmediata según resultado:**
- Si >30% por **horarios** → Abre un horario más
- Si >30% por **precio** → Ofrece plan de pagos
- Si >30% por **falta de interés** → Revisa metodología, añade eventos

## ⚠️ REGLA DE ORO

> **Si un indicador está EN ROJO dos meses seguidos → ACTUAR INMEDIATAMENTE**

No esperar al tercero. Ejemplos de acción:

- **Ocupación roja 2 meses** → Revisar precio, lanzar referidos, ir a colegios
- **Retención roja 2 meses** → Encuesta a madres, revisar método de enseñanza
- **Margen rojo 2 meses** → Aumentar precio O reducir gastos
- **Dependencia >75% 2 meses** → Contratar profesor urgente

---

## 🔴 SEÑALES DE PELIGRO (ACT NOW)

Si ves CUALQUIERA de estas, no esperes:

1. **Saldo final negativo 2 meses** → Problema de flujo de caja. Reduce gastos HOY.
2. **Conversión pregunta→prueba <20%** → Precio demasiado alto o comunicación confusa.
3. **Abandono mes 1-2 >20%** → Problema crítico con alumnas nuevas. Revisa primeras clases.
4. **NPS <30** → Insatisfacción generalizada. Encuesta urgente.
5. **0 referidos 2 meses** → Alumnas no recomiendan. Satisfacción muy baja.

## 📞 CUANDO CONTACTAR A ASESOR

Contacta si:

1. **Cuadro de Mando tiene 2+ rojos 2 meses seguidos** → Necesita intervención
2. **Ocupación < 40% después de 3 meses** → Producto/mercado no encaja
3. **Saldo flujo caja negativo** → Puede cerrar en 3 meses
4. **Dependencia > 75% después de 6 meses** → Estructura insostenible
5. **Consideras abrir segundo local** → Requiere análisis

## ✅ RESUMEN: QUÉ RELLENAR CADA MES

```
CADA PRIMER LUNES (20 minutos):

1. Estado Resultados → Llenar 8 células amarillas
2. Cuadro Mando → Calcular y llenar 10 KPIs
3. Si algo rojo → Análisis Abandono (5 min extra)

TRIMESTRAL (10 minutos):
- Modelo Financiero: Actualizar supuestos
- NPS: Encuesta 5-10 madres
- Canales: ¿Dónde vinieron las nuevas alumnas?
- Cohortes: ¿Retención mejor en el tiempo?

ANUAL (1-2 horas):
- DAFO: Revisar fortalezas/debilidades
- Calendario: Planificar temporadas
- Riesgos: Actualizar contingencias
- Ventaja Competitiva: ¿Mejoró defensibilidad?
```
