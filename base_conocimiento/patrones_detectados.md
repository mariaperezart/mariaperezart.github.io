# Patrones detectados — FARO

Patrones de comportamiento del ICP (clínicas dentales, decisor, recepción) observados a través de experimentos reales. Cada entrada la añade el Agente de Aprendizaje al cerrar un experimento, solo si tiene un dato del Analizador que la respalde.

Formato de cada entrada:

```
## [Patrón, en una frase]
- Detectado en: EXP-XXX
- Evidencia: [dato concreto del análisis de resultados]
- Confianza: baja / media / alta (según nº de experimentos que lo confirman)
```
