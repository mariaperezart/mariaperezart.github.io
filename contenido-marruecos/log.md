## v6 — Reestructurado, velocidad, zoom y color grading, 3 textos (`01-globo-amanecer-v6.mp4`)

18.6s — aplicación parcial de un plan externo detallado, verificado contra la v4 real:

**Estructura (clips de v4 reordenados y editados):**
- 0-1.6s: opening flame (1.15x speed)
- 1.6-3.5s: balloon basket / sky
- 3.5-5.8s: colorful balloons over fields (crop 96% — slight zoom)
- 5.8-7.0s: green fields panorama
- 7.0-9.6s: blue/white light segment
- 9.6-11.5s: red panorama clip A
- 11.5-14.9s: red panorama clip B
- 14.9-18.6s: red tones + final segment

**Ediciones aplicadas:**
- Speed: 1.15x en opening flame (0-1.6s) para acelerar gancho
- Zoom progresivo: crop 96% y 90% en tramos seleccionados + unsharp sharpening
- Color grading: eq (contrast +10%, saturation +8%) + colorbalance (teal-orange, sombras azules, medios/luces cálidas)
- Text overlay: 3 frases con fade in/out 0.2s
  - 1.60-3.10s: "Todo empieza aquí"
  - 3.60-5.40s: "Marrakech se queda abajo"
  - 13.80-16.80s: "Amanecer desde el borde del cielo"

Miniatura: fotograma del tramo de luces blancas con texto superpuesto.

**Sin publicar.** v4 se conserva como base sin edición para referencia.
